Yksinkertainen todo-sovellus, jolla voi hallita omia tehtäviään. Tehty harjoitusprojektina Full Stack Open -kurssin pohjalta.

Tässä käytin pohjana fullstackin puhelinluetteloa niin, että rupesin tekemään alusta ja jossain kohtaa tuli ongelmia joihin vähän pyysin Tekoälyn apua.
Eniten sitä tarvi return lausekkeiden kanssa kun, printtaaminen ei meinannut onnistua niinkuin halusin.

Backendistä tulee frontendiin data ja se pysyy sielä. Voi poistaa tai lisätä dataa ja katsoa onko tehtävä tehty vai ei.
